# 봇별 그룹(User-agent: GPTBot 등)을 일부러 만들지 않는다. 크롤러는 자기
# 이름의 그룹이 있으면 User-agent: * 를 통째로 무시하기 때문에, 봇마다
# 그룹을 파면 아래 Disallow 가 그 봇에게만 사라진다. 한 줄 허용하려다
# 잠가둔 곳이 열린다.
#
# AI 크롤러 정책은 이 파일이 정하지 않는다 — Cloudflare 대시보드의 관리형
# robots.txt 가 이 내용 앞에 자기 블록을 붙인다(현재 GPTBot·ClaudeBot·
# Google-Extended·CCBot·Applebot-Extended 등에 Disallow: / ). 바꾸려면
# 거기서 끈다. 파일에서 Allow 로 덮어쓰려 하면 같은 봇에 Disallow 와
# Allow 가 동시에 걸린 모순된 파일이 된다.
#
# 검색에 내보내지 않는 곳:
#   /oauth/     Threads 인증 코드를 받는 일회성 유틸리티
#   /design/    내부 디자인 토큰 참조
#   /link/      인스타 바이오 착지용 — 홈과 경쟁시킬 이유가 없다
#
# 낱장 아트보드(/cards/<세트>/<번호>/)는 여기서 막지 않는다. 페이지마다
# noindex, nofollow 가 붙어 있고, robots.txt 로 막으면 크롤러가 그 태그를
# 읽지도 못해 오히려 색인에 남는다.

User-agent: *
Allow: /
Disallow: /oauth/
Disallow: /design/
Disallow: /link/

Sitemap: https://jupocket.com/sitemap-index.xml
