# 전세 도우미(채팅) — 설계와 다음 단계 (2026-11-08)

## 왜

전세를 처음 하는 사람은 **언제 무엇을 해야 하는지**를 모른다. 이 도우미의 첫째 목적은 일정이다:
"몇 월 며칠(무슨 요일)에 무엇을 해야 하나". 그 위에 어려운 말 풀이, 상황별 할 일, 집주인과 연락할 때
기록을 남기는 법을 얹는다. AI는 나중에 붙인다 — 지금은 AI 없이도 핵심이 돌아가야 한다(사용자 결정).

## AI 리허설(실 API 없이)

- 질문: `workers/api/src/__tests__/fixtures/hug-cases.json`
- 모델 답: Claude Code 서브에이전트(Haiku)로 녹화 → `hug-recorded.json` (근사치)
- 재생 테스트 `hug-replay.test.ts` 가 서버 검사(숫자 검사·계산·다시 시키기)를 그대로 거친다
- 독자에게 보일 답 예시: `docs/hug-chat-rehearsal.md` (`npx vite-node scripts/hug-rehearsal.ts report`)
- 실 API 키(Anthropic 등)가 생기면 같은 질문을 실제로 다시 녹화해 비교한 뒤 서버 모델을 바꾼다

## 하지 않는 것(지금)
