## 1. 노출은 이미 100% 남의 피드다

Threads 인사이트(최근 30일, 계정 대시보드에서 직접 읽음):

| 항목 | 값 |
|---|---|
| 조회수 | 13,121 |
| 조회한 사람 | 10,672 |
| **팔로워** | **0명 (0.0%)** |
| **팔로워가 아닌 사람** | **10,672명 (100%)** |
| 순 팔로워 | +1 |
| 반응 | 3 |

팔로워가 4명이므로 당연한 결과지만, 뒤집으면 **팔로워를 늘리는 일은
지금 노출과 무관하다.** 배포는 전적으로 추천 알고리즘이 한다.

그리고 **반응 3 / 조회 13,121 = 0.02%** 다. 배포는 됐고 사람은 봤는데
아무것도 하지 않았다. 문제는 도달이 아니라 그다음이다.

같은 기간 사이트 세션은 25였다(GA4). 그중 스레드 referral 로 식별된 것은
7일 기준 2건이다.

### 조회한 사람의 관심사

인사이트가 주는 상위 커뮤니티: AI Threads 36 · 여행 26 · Investing 21 ·
맛집 17 · 결혼준비 14. **세금은 없다.** 인접한 건 Investing 하나다.
우리 글은 세금 관심층이 아니라 일반 피드에 얹혀 나가고 있다.

### 조회한 사람이 활동하는 시간

일요일 15–18시(8.4천명), 월요일 06–09시(4.6천명). 이것은 *독자가 접속하는*
시간이지 우리가 올린 시간이 아니다. 예약 시각을 여기에 맞춰 본 적은 아직 없다.

## 2. 조회수는 연속이 아니라 계단이다

글을 조회수 순으로 세우고 이웃 사이 배수를 봤다.

| 조회수 | 직전 대비 | ♥ | 글 |
|---:|---:|---:|---|
| 2,320 | — | 1 | 014 가산세 감면 기한 |
| 1,956 | 1.19× | 1 | 016 하루 차이 4만원 |
| 1,772 | 1.10× | 0 | 009 상한액은 7월 |
| **584** | **3.03×** | 0 | 011 납부예외 ← **끊김** |
| 583 | 1.00× | 0 | 004 지금 내는 게 끝이 아니다 |
| 569 | 1.02× | 0 | 007 많이 벌어도 상한 |
| 318 | 1.79× | 0 | 015 가산세 두 종류 |
| … | | | |
| 49 | 1.92× | 0 | 023 지연발급 vs 미발급 |
| **11** | **4.45×** | 0 | 001 보험료율 9.5% ← **끊김** |
| 7 · 3 · 1 · 0 · 0 · 0 | | 0 | |

**끊기는 자리가 두 곳이다.**

- **584 ↔ 1,772** — 그 사이에 글이 **하나도 없다.** 1,000이 이 구간 안에 있다.
- **49 ↔ 11** — 아래쪽 6편은 사실상 배포되지 않았다.

세 층으로 갈린다: 확산 3편(1,772+) · 기본 13편(49~584) · 미배포 6편(0~11).

> "1,000회를 넘으면 다른 피드로 퍼진다"는 관찰과 **우리 데이터가 어긋나지
> 않는다.** 584와 1,772 사이가 비어 있고 1,000이 그 안이다. 다만 n=22라
> 이것이 임계값인지, 우연히 생긴 빈칸인지는 아직 가를 수 없다.
> 편수가 늘면 이 표를 다시 그린다.

### 아닌 것으로 확인된 설명

| 가설 | 결과 |
|---|---|
| 시간대 | **아니다.** 같은 날 09:30 글 203 vs 09:36 글 2,320 — 6분 차이에 11배 |
| 직전 글과의 간격 | **아니다.** 45분 미만 구간의 평균이 오히려 가장 높다 |
| 계정 나이 | 부분적. 09-11 두 편만 설명하고 나머지는 못 한다 |

확산한 3편의 공통점은 **손해를 되돌릴 수 있다**는 말이다 — 가산세 감면
둘, 시기 오해 교정 하나. 좋아요 3개 중 2개도 이 셋에 붙었다. n=3이라
여기까지만 적는다.

## 3. 다른 계정은 어떻게 쓰는가

Threads 검색(절세 · 종합소득세 · 국민연금)에서 반응 상위 글을 봤다.
**조회수는 작성자만 본다** — 남의 계정은 좋아요·답글·리포스트·공유만
공개된다. 그래서 "1만 조회 글"로 고를 수는 없고 반응으로 대신했다.

수치는 `좋아요 / 답글 / 리포스트 / 공유`.

| 계정 | 성격 | 반응 |
|---|---|---|
| `financial_planning_pro` | 자기소개 · 반말 · 이모지 · 이력 나열 | **1.6천 / 956 / 1.2천 / 5** |
| `kim.e.z` | 시사 목록글 | 1.5천 / 416 / 57 / 18 |
| `gptaku_ai` | 1인칭 경험담 "나도 기장료가 아까워서…" | **381 / 86 / 98 / 169** |
| `y__oooooooon` | 일반인 질문 · 도와달라 · ㅜㅜ | **217 / 178 / 19 / 34** |
| `kmstax_official` | 반말 · 독자 호명("스친들") · 댓글 유도 | 87 / 11 / 16 / 6 |
| `yong_tax_` | 7장 캐러셀 · 상담 어투 | 85 / 12 / 32 / 27 |
| `lilatax` | 이모지 구분 목록 · 정보 나열 | 20 / 2 / 2 |
| `jjeong6629` | 번호 단계 + "다음 글에서 풀어드릴게요" | 9 / 6 / 3 |
| `taxbonbu1` | **존댓말 · 문어체 · 정확한 설명** | **2 / 1** |
| 주포켓 (우리) | 존댓말 · 문어체 · 조문 인용 | **1 / 0** (조회 2,320일 때) |

`taxbonbu1` 이 우리와 가장 닮았다. 내용은 정확하고 3.3% 환급이라는 좋은
주제인데 반응이 2다. **우리 문체가 안 튀는 게 우연이 아니라는 뜻이다.**

### 갈리는 지점 네 가지

1. **말투** — 반응 상위는 반말·구어체(`~함`, `~거든`, `~할게`). 우리는
   전편이 `~습니다`.
2. **1인칭** — "나도 ~해봤다", "내 경우엔". 우리는 화자가 없다.
3. **말 걸기** — 질문으로 끝내거나 댓글을 부른다. 우리 글은 결론으로 닫힌다.
4. **다음 편 예고** — "다음 글에서 풀어드릴게요". 우리는 매 편이 완결이다.

반응이 가장 큰 글이 **전문가 글이 아니라 일반인의 질문**이라는 점
(`y__oooooooon`, 답글 178개)이 이 표에서 가장 중요한 한 줄이다.

### 하지 않을 것

- 남의 글 문장을 옮기지 않는다. 구조만 본다.
- 캡처 이미지를 가져다 쓰지 않는다.
- **정확성을 말투와 바꾸지 않는다.** 말투는 문체의 문제지 숫자의 문제가
  아니다. `src/rates/*.json` 검증 규칙은 그대로다.

## 4. 실험 — 말투 A/B (2026-09-16 시작)

3절이 말한 네 가지 차이 중 **질문형 · 1인칭 · 말 걸기** 를 시험한다.
반말은 쓰지 않았다 — 세금 사이트의 목소리를 버리는 판단은 결과를 보고
한다.

**같은 주제 안에서 비교한다.** 증여세 다섯 편이 전부 `/guide/gift-tax/` 를
가리켜 주제·난이도·독자가 같고, 같은 이틀 안에 나간다. 바꾼 것은 문체뿐이다.

| | 대조군 (문어체) | 실험군 (질문형·1인칭) |
|---|---|---|
| 글 | 029 · 030 · 031 | 027 · 028 |
| 게시 | 09-16 11:00 / 12:30 / 14:00 | 09-17 07:30 / 09:00 |
| 첫 줄 | "결혼할 때 부모님께 받는 돈은 1억 5천만원까지 세금이 없습니다." | "부모님께 받는 5천만원, 한 번 쓰면 끝일까요?" |
| 끝 줄 | 결론으로 닫음 | 질문으로 열어 둠 |

> **처음에 부가세 가산세(024·025·026)로 잡았다가 옮겼다.** 실험군으로
> 삼으려던 024·026 이 고쳐 쓰기 **전에** 이미 나가 버렸다(16:00, 20:41).
> `npm run queue` 의 요약 줄만 읽고 "내일로 넘어감 3건" 을 024·025·026 으로
> 본 것이 원인이다 — 실제로는 025·027·028 이었다. 저장소의 024·026 은 실제
> 게시본으로 되돌렸다. **게시 예정 글을 고칠 때는 요약이 아니라 표의 그 줄을
> 본다.**

**바꾸지 않은 것** — 숫자·조문·`at:`·파일명·`ref`. 세 편 모두 변경 전후의
백분율과 조문 인용이 문자열 단위로 같은지 기계로 대조했다. 문체 실험이
숫자를 흔들면 실험이 아니라 사고다.

**무엇을 볼 것인가.** 조회수만 보지 않는다 — 1절이 보여준 대로 조회는 이미
1만인데 반응이 3이다.

1. **반응**(좋아요·답글) — 이 실험의 주 지표
2. **유입** — `npm run seo` 의 GA4 유입 출처에서 `utm_campaign` 027·028
3. 조회수 — 2절의 세 층 중 어디에 앉는지

### 1차 결과 (2026-09-18)

| | 대조군 (문어체) | 실험군 (질문형) |
|---|---|---|
| 029 혼인·출산 | 232 · ♥1 | |
| 030 신고기한 3개월 | 341 · ♥0 | |
| 031 형제 한도 | 167 · ♥0 | |
| 028 부모는 한 사람 | | 298 · ♥0 |
| 027 10년 리셋 | | **아직 안 나감** |
| 평균 | 247 (경과 46~49h) | 298 (경과 26h) |

**판단하지 않는다.** 실험군이 한 편뿐이고 경과 시간이 절반이다. 298 이
247 보다 높지만 n=1 에 조건도 다르다.

**다만 주 지표는 움직이지 않았다** — 실험군 좋아요 0, 답글은 우리 링크
답글 1개뿐. 조회가 아니라 반응을 보려던 실험인데 반응은 양쪽 다 0 이다.

027 은 `at: "07:30"` 이라 그 시각에 PC 가 꺼져 있어 유예 창을 계속 넘긴다.
슬롯을 옮기지 않는다(예약 순서를 흔들지 않는 규칙). 나가면 여기에 덧붙인다.

### 같은 날 확인된 정정

어제 "가이드 페이지 참여 세션 0" 이라고 적었다. 세션이 45→59 로 늘자
뒤집혔다.

| | 09-17 | 09-18 |
|---|---|---|
| `/guide/gift-tax` | 5세션 참여 **0** | 5세션 참여 **3** · 29초 |
| `/guide/vat-penalty` | 2세션 참여 0 | 4세션 참여 1 · 13초 |
| `/guide/family-deduction` | 3세션 참여 0 | 3세션 참여 1 · 11초 |

**한 자리 숫자에서 0 이 나온 것을 신호로 읽은 것이 틀렸다.** 이 정정으로
"체류가 10초를 못 넘어 전면광고 새 트리거가 안 걸린다"는 어제의 주장도
근거가 약해진다 — 일부 페이지는 넘긴다.

셋 다 나간 뒤 48시간에 `npm run stats` 로 찍고 여기에 결과를 덧붙인다.
대조군이 3편, 실험군이 2편이라 **차이가 작으면 판단하지 않는다.** 반응이
0에서 0으로 같으면 문체가 아니라 다른 것이 원인이라는 뜻이고, 그때는
3절의 나머지 두 가지(반말·다음 편 예고)로 넘어간다.

## 5. 아직 모르는 것

- 1,000이 임계값인지, n=22의 우연인지
- 말투를 바꾸면 반응이 오르는지 — 한 번도 시험하지 않았다
- 독자 활동 시간(일 15–18시 / 월 06–09시)에 맞춰 올리면 달라지는지
- 인스타는 조회 0이 계속된다. 계정 나이 탓인지 다른 이유인지
