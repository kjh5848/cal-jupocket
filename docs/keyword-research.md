# 한국형 계산기 사이트 — 키워드 조사 보고서 (v1)

작성 2026-08-06 · 방법: 네이버 데이터랩(상대 검색 추이) + 네이버 웹문서 SERP 구성

## 방법과 한계 (먼저 읽을 것)

- **절대 검색량은 이 조사에 없다.** 네이버 공개 API는 절대량을 안 준다 — 그건
  네이버 검색광고 **키워드도구**(searchad)에서 뽑아야 한다(보험 프로젝트의 GKP와
  같은 위치). 아래 숫자는 전부 **상대 관심도**다.
- 기준(anchor) = `퇴직금 계산기`. 세 배치 모두에 넣어 배치 간 비교가 되게 했다.
  아래 값은 anchor의 12개월 평균을 100%로 놓은 상대치.
- SERP는 후보 전체가 아니라 우선 2건만 직접 확인했다(연차수당·프리랜서3.3).
  나머지는 관심도만 확정, SERP는 채택 전 확인 필요.

## 2. SERP 경쟁 (직접 확인 2건)

### 프리랜서 3.3 계산기 — ✅ ADOPT (약한 SERP = 틈)
- 문서 총량 **18.9만** (연차수당 180만의 1/10 — 경쟁 얕음)
- 상위: withholding.kr · k-calc.com · pluuug · jongso.ryunadb.kr · savingtax.kr ·
  calcwolrd — **거의 전부 소규모 독립 계산기 사이트.** 네이버·토스·사람인 벽 없음
- **신규 사이트가 랭킹 가능한 명백한 증거.** 5월 종소세 환급철과 엮여 재방문성,
  프리랜서 인구 증가 추세

### 연차수당 계산기 — 🟡 WATCH (혼잡)
- 문서 총량 180만
- 상위: 노동OK(nodong.kr) · 사람인 · 고용노동부 노동포털 등 **권위 사이트 존재**,
  단 glasswallet·work.calculate.co.kr 등 소규모도 랭킹 = 깊이로 진입 여지는 있음

## 3. 판정 — SERP 틈 전략의 스위트스팟

**head 노동/급여 계산기(퇴직금·연봉실수령·실업급여·4대보험·주휴수당)는
관심도 최상위지만 네이버 자체 계산기·토스·사람인·노동OK가 점령 → 신규 사이트
정면 승부 불리.** 보험에서 head term 피한 것과 같은 논리.

**틈이 확인된 축 = 프리랜서 3.3% / 종합소득세 환급 클러스터:**
- 관심도 중간(~8%)이지만 SERP가 소규모 사이트뿐(약함)
- 5월 신고철 재방문 + 프리랜서 증가 = 상승 추세
- "환급액 얼마?"는 값을 넣어야 나오는 산출물 → AIO/검색답변이 대체 못 함

**확인 필요(관심도는 있으나 SERP 미확인):** 양도소득세(~28)·취득세(~17)·
증여세(~8)·상속세(~3.3) — 부동산/자산세는 복잡해 세무사 블로그·전문 계산기
사이트(부동산계산기·셀리몬)가 나눠 갖는 경향. 네이버 직접 점령은 덜해 틈 가능성.
채택 전 SERP 확인 요.

## 4. 권장 다음 단계

1. **1차 클러스터 후보 = 프리랜서 3.3% / 종소세 환급** (SERP 틈 확인됨)
2. 부동산/자산세(양도·증여·상속·취득) **SERP 4건 추가 확인** → 틈이면 2차 클러스터
3. 절대 검색량은 **네이버 검색광고 키워드도구**에서 위 shortlist를 뽑아 교차검증
   (보험 GKP처럼) — 상대 관심도만으로는 규모 확정 불가
4. 그 뒤 브레인스토밍 재개: MVP 규모·도메인·애드센스 계정·세율 갱신 구조 확정 →
   설계 문서 → 구현 계획
